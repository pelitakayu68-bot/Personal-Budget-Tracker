# Personal-Budget-Tracker
A professional-grade financial tracking system for engineering and technical project management.

Precision Ledger is a lightweight, high-performance web application designed to track income and expenses with an emphasis on data clarity and industrial aesthetics. This project was developed as part of the BMKT 1723 Computer Programming curriculum to demonstrate the application of core logic in a modern development environment.

🚀 Features

Transaction Logging: Record revenue and expenditures with specific technical classifications.


Real-time Analytics: Automated calculation of net balance and liquidity through iterative logic loops.
+1


Data Persistence: Integrated browser local storage ensures your ledger data remains secure across sessions.


Validation Engine: Built-in error handling to prevent data corruption from invalid numerical inputs.
+1

Industrial UI: A clean, high-contrast interface designed for maximum data readability.

🛠️ Technical Stack
Frontend: HTML5, CSS3 (Modern Grid/Flexbox)

Logic: JavaScript (ES6+)

Storage: Browser LocalStorage API

📂 Project Structure

├── index.html   # Application structure and UI components
├── style.css    # Professional/Engineering styling and layout

⚙️ Core Concepts Applied
This software implements several fundamental programming principles:


Arrays: Used for structured storage of transaction records.


Loops: Used for processing multiple datasets to generate financial reports.


Functions: Modularized code for calculation and UI rendering.


Selection Logic: Conditional statements for input validation and credit/debit categorization.
